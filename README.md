# CloudpunkDSIcons

Source code for my Cloudpunk mod, 'Playstation Button Prompts for Cloudpunk'. This is a BepInEx plugin that replaces the Xbox button prompts in Cloudpunk (and City of Ghosts) with PlayStation button prompts.

Images are not included.

You can download the full mod on [Nexus Mods](https://www.nexusmods.com/cloudpunk/mods/8).
